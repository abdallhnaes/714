# Derby Pro - العمران V4

تطبيق أندرويد احترافي لإدارة ديربي بين فريقين.

## ماذا يوجد في التطبيق؟
- شاشة علوية تعرض عدد انتصارات كل فريق وعدد التعادلات.
- خطة الفريق الأول.
- خطة الفريق الثاني.
- إدخال أسماء لاعبي الفريقين.
- اختيار خطة كل فريق: 3-3-1 / 3-2-2 / 2-3-2 / 1-3-3.
- إدخال نتيجة المباراة بعد تنزيل خطة الفريقين.
- سجل نتائج الديربي.
- تحديث عدد الانتصارات تلقائيًا بعد كل نتيجة.
- تصميم ملعب قريب من الحقيقة: عشب، خطوط، مدرج، إطار ملعب.
